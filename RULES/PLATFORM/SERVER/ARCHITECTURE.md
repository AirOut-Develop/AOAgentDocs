# 서버 적용 규칙

- HTTP/API 계약, 제품 정책, 저장소/외부 서비스의 책임을 구분한다.
- 계정/서비스/기기 신원과 리소스 접근권한을 분리해 명시적으로 검증한다.
- 장기 요청/스트림의 취소·타임아웃·재연결·중복 실행을 테스트한다.
- 실행 모델/벤더 선택은 서버 정책이며 앱이 런타임 세부사항을 복제하지 않게 한다.
- API 하위 호환, DB 변경, 배포/롤백 단계를 기록한다.
- 공유 GPU/포트/볼륨/호스트 변경은 해당 운영 정본과 권한을 확인한다.
- 테스트/문서 도구는 운영 DB나 실제 사용자 데이터에 암묵적으로 연결하지 않는다.
- 환경변수·비밀·로그 정책은 별도 관리하고 샘플/배포 ZIP에 실제 값을 넣지 않는다.
