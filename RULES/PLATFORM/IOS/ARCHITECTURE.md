# iOS 네이티브 적용 규칙

- 화면 상태와 서버 DTO를 분리한다. 카메라/오디오/보안 저장소/렌더러는 기기 책임이다.
- 사용자 계정·대화 권한·모델 정책은 서버 계약으로 정의한다.
- 앱 복귀/네트워크 단절/권한 거절/오디오 인터럽션을 검증한다.
- 최소 OS, bundle ID, 빌드 번호, 서명과 배포 채널은 제품 문서가 정한다.
- 시뮬레이터 통과와 실제 기기 인증/카메라/음성 검증을 분리한다.
- 플랫폼 간 fixture는 공유하되 UI/렌더링 구현 통합을 강제하지 않는다.
- 서명 키·세션·사용자 사진·원시 인증 로그는 킷에 넣지 않는다.
