[AOAgentDocs 1.3.1 신규/선택 이관]

대상 프로젝트와 원본 킷의 Git root/remote/dirty 상태를 먼저 확인한다.
기존 프로젝트 지침을 읽고 원본 킷은 대상 디렉터리 바깥에서 실행한다.
Python 3.10+ 표준 라이브러리를 사용한다.

1. python3 scripts/aodocs.py install TARGET --profile server --profile ios
   기본 dry-run을 검토한다. 필요한 platform은 server/ios/android/web 중 복수 선택.
2. 같은 명령에 --apply를 추가한다.
3. .aodocs/kit(관리 파일), manifest.json(설치 버전/hash), project.json/documents.json(사용자 소유)을 확인한다.
4. 향후 플랫폼은 project.json planned_platforms에 둔다. 초기 --profile은 활성 플랫폼이다.
5. 기존 RULES/AGENTS/CLAUDE/README/CONTRIBUTING/.aodocs_version과 docs 이력은 덮어쓰지 않는다.
6. .aodocs/kit/examples/lifecycle에서 필요한 PRD/계획/검증만 실제 docs에 복사하고 documents.json에 연결한다.
7. 프로젝트 문서 지도에 킷 지침/registry의 상대 링크를 추가한다. 자동 규칙 승격은 하지 않는다.
8. python3 scripts/aodocs.py validate TARGET
9. 실제 제품 테스트는 별도로 실행하고 미검증 항목을 그대로 남긴다.

.aodocs/는 Git 추적 대상이며 비밀/개인 로그를 넣지 않는다.
root의 옛 .aodocs_version은 legacy root 복사본의 버전이다. 새 설치 버전은 .aodocs/manifest.json이 정본.
설치기는 source/target 중첩, symlink, 경로 탈출, 기존 관리 파일 수정 충돌을 거부한다.
원자적 동시 설치는 지원하지 않는다. 중단되면 diff 확인 후 복구하고 동시 실행하지 않는다.

1.3.1은 .aodocs/.gitattributes도 설치한다. 속성 파일과 kit 바이트의 Git 자동 줄바꿈 변환을 방지한다.
기존 속성 파일 내용이 다르면 덮어쓰지 않고 중단한다. 프로젝트 root .gitattributes는 변경하지 않는다.
