# AOAgentDocs 1.4.1

리드 세션이 태스크만 배분하고 역할이 고정된 세 패널을 상주시키는 운영 구조를 규칙에 추가했습니다.

- `RULES/COMMON/SESSION_HANDOFF.md`: 리드 1 + 구현 · 문서·PRD · 검증 3패널 상주 구조
- 리드는 직접 편집하지 않고 입력·성공 조건·금지사항이 있는 태스크로 나눠 담당 패널에 전달
- 한 파일의 소유 패널 명시, 저작 패널과 검증 패널 분리, 자기 승인 금지
- 리드 메인 : 우측 패널 열 = **6 : 4** 너비, 우측 열은 3등분하고 위에서부터 구현·문서·검증 고정
- `examples/lifecycle/STATUS.md`: 지금 할 일과 후속 대기열에 담당 패널 항목 추가

패널 구조는 권장 운영 방식이며 단일 세션 사용을 막지 않습니다. 상태 정본은 여전히
`.aodocs/documents.json`과 연결 문서이고, 태스크를 배분한 사실은 완료 근거가 아닙니다.

전체 테스트 87개 통과. 1.4.0의 비파괴 설치·Git 바이트 보존·legacy 파일 보존을 유지합니다.
