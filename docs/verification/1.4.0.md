# AOAgentDocs 1.4.0 — 세션 인수인계 규칙 검증

## 범위

장기 작업의 `docs/STATUS.md` 대시보드, 세션 시작·종료 및 현황보고 규칙을 추가한다.
registry와 PRD/PLAN/WRK/ISS/verification/release가 상태 정본이며 STATUS는 파생 정보다.
설치기는 프로젝트별 STATUS 내용을 만들거나 덮어쓰지 않는다.

## 한계

STATUS의 실제 내용이 registry와 의미상 일치하는지는 자동 생성하지 않는다.
현황보고 때 registry를 새로 읽어 사람이/에이전트가 갱신해야 한다.
이 규칙은 대화 세션 자체의 저장/복구 기능이 아니며 특정 Codex CLI 세션 손상을 고치지 않는다.
native Windows/macOS 실행은 이번 검증 범위 밖이다.
